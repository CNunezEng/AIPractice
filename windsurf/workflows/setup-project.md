# Setup Project Workflow

This workflow creates a new project following the standards defined in AIinfo.txt.

## Steps

1. Create project directory structure
   - Create main project folder
   - Set up src/, tests/, docs/ subdirectories

2. Generate standard documentation
   - Create README.md with project name, purpose, build/run instructions
   - Set up user input log template

3. Implement testing framework
   - Create unit test structure
   - Set up runtime input file for test cases
   - Configure git hooks for automated testing

4. Code structure setup
   - Define interfaces for major components
   - Set up dependency injection patterns
   - Create error handling utilities

5. Review and validate
   - Check for edge cases
   - Ensure error messages are explicit
   - Verify no unnecessary abstraction
   - Confirm single responsibility principle adherence
